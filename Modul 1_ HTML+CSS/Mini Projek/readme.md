# Praktikum Modul 1 - CodeCamp

## Ringkasan halaman

CodeCamp adalah landing page statis untuk program belajar coding bagi mahasiswa dan pemula.

Halaman ini berisi:
- Navigasi
- Hero section
- Program pembelajaran
- Benefit
- Informasi kegiatan
- Call to Action (CTA)
- Footer

## Tiga keputusan teknis

1. Menggunakan semantic HTML seperti `header`, `nav`, `main`, `section`, `article`, dan `footer`.
2. Menggunakan Flexbox untuk mengatur layout navigasi, program, benefit, dan informasi.
3. Menggunakan media query agar halaman responsive pada berbagai ukuran layar.

## Masalah, diagnosis, dan perbaikan

Masalah yang ditemukan adalah tampilan perlu disesuaikan pada ukuran layar yang lebih kecil.

Perbaikan dilakukan dengan menggunakan media query dan mengatur ukuran elemen agar halaman tetap rapi dan tidak mengalami horizontal overflow.

## Hasil pengujian empat viewport

| Viewport | Hasil |
|---|---|
| 320px | Lulus, tidak overflow |
| 375px | Lulus, tidak overflow |
| 768px | Lulus, tampilan rapi |
| 1024px | Lulus, tampilan rapi |
