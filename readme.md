# Proyek 3 - Rena Fiantina / 251511028

## Deskripsi

Proyek 3 merupakan kumpulan praktikum pengembangan perangkat lunak berbasis web yang dikerjakan secara bertahap.

Pada proyek ini, pengembangan website dimulai dari pembuatan landing page statis menggunakan HTML dan CSS pada Modul 1, kemudian dikembangkan menjadi landing page interaktif menggunakan Vanilla JavaScript pada Modul 2.

## Tujuan

Proyek ini bertujuan untuk memahami proses pengembangan halaman web dari struktur dasar hingga penambahan interaksi.

Materi yang diterapkan meliputi:
- HTML semantik
- CSS
- Box model
- Flexbox
- Responsive design
- Media query
- JavaScript
- Array dan object
- DOM manipulation
- Event listener
- Validasi form
- Perubahan class dan state
- Debugging menggunakan browser dan DevTools
- Pengujian responsif dan keyboard

## Modul yang dikerjakan

### Modul 1 - HTML + CSS

Modul 1 berfokus pada pembuatan landing page statis menggunakan HTML dan CSS.

Pada tahap ini dibuat struktur halaman CodeCamp yang terdiri dari:
- Header
- Navigasi
- Hero section
- Bagian informasi atau manfaat
- Call to action
- Footer

HTML menggunakan elemen semantik dan CSS digunakan untuk mengatur tampilan, layout, spacing, serta responsive design.

Flexbox digunakan untuk membantu menyusun layout dan media query digunakan agar halaman dapat menyesuaikan ukuran layar.

Hasil dari Modul 1 kemudian digunakan sebagai dasar untuk pengembangan Modul 2.

### Modul 2 - Vanilla JavaScript dan Interaktivitas Web

Modul 2 mengembangkan landing page CodeCamp menjadi halaman interaktif menggunakan Vanilla JavaScript.

Fitur yang diterapkan:
1. Navigasi mobile
2. Daftar program dinamis dari array of objects
3. Filter daftar program
4. FAQ accordion
5. Form kontak dengan validasi
6. Tombol kembali ke atas
7. Perubahan tema menggunakan class

JavaScript diletakkan pada file eksternal `js/app.js` dan dijalankan menggunakan `defer`.

Interaksi pengguna menggunakan `addEventListener` dan perubahan tampilan dilakukan melalui DOM serta class CSS.

## Teknologi

Teknologi yang digunakan dalam proyek ini:

- HTML5
- CSS3
- Vanilla JavaScript
- Visual Studio Code
- Browser
- Live Server
- Git dan GitHub

Tidak digunakan framework atau library UI dalam Mini Project Modul 2.
