## Ringkasan Modul

Modul 2 membahas penggunaan Vanilla JavaScript untuk menambahkan interaksi pada halaman web. Materi yang dipelajari meliputi JavaScript dasar, DOM, event, array dan object, validasi form, asynchronous JavaScript, serta debugging.

Pada modul ini terdapat beberapa eksperimen, tugas praktikum, independent challenge, homework, dan mini project.

## Materi yang dipelajari

Materi utama yang dipelajari pada Modul 2 yaitu:

- Variabel, tipe data, dan operator JavaScript
- Percabangan dan perulangan
- Function dan scope
- Array dan object
- DOM dan manipulasi halaman
- Event dan interaksi pengguna
- Validasi form
- Promise dan async/await
- Fetch untuk mengambil data
- Debugging JavaScript
- Console dan Network pada DevTools

## Eksperimen

Beberapa eksperimen yang dikerjakan pada Modul 2 meliputi:

- Eksperimen Console
- Eksperimen DOM dan Event
- Eksperimen Promise dan Fetch
- Eksperimen Diagnosis Error JavaScript

Eksperimen digunakan untuk memahami cara kerja JavaScript dan mengetahui cara menemukan serta memperbaiki kesalahan pada program.

## Tugas Praktikum

Tugas praktikum terdiri dari beberapa tahap:

- Task 1 - JavaScript Logic Builder
- Task 2 - DOM dan Form Controller
- Task 3 - Asynchronous JavaScript Data Loader

Task 1 berfokus pada pembuatan function dan pengolahan data.

Task 2 menggabungkan data, DOM, event, dan validasi form.

Task 3 mempelajari asynchronous JavaScript menggunakan JSON dan fetch serta menangani beberapa kondisi seperti loading, success, empty, dan error.

Independent challenge digunakan untuk menerapkan materi JavaScript melalui latihan tambahan.
